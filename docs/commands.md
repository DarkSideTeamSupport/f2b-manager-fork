# Руководство по командам f2b-manager

> Все команды отправляются Bot в личном чате Telegram.
> **Уровни доступа**: `admin` (администратор, полный доступ) > `operator` (оператор, запросы и уведомления) > неавторизованный пользователь (только `/start` и `/help`).
> Команды с ограниченным доступом от неавторизованных пользователей молча отклоняются.

---

## Обзор прав доступа

| Уровень | Источник chat_id | Доступные команды |
|------|--------------|------------|
| **admin** | `config.yaml` → `telegram.admin_chat_ids` | Все 17 |
| **operator** | `telegram.operator_chat_ids` | `/start` `/help` `/status` `/jails` `/banned` `/jail` `/report` `/setnotify` `/stats` |
| Неавторизованный | — | `/start` `/help` (остальные отклоняются) |

---

## Подробное описание команд

### 1. `/start`
- **Доступ**: все пользователи
- **Назначение**: показывает приветствие и текущий `chat_id`, который можно добавить в `admin_chat_ids`.
- **Аргументы**: нет
- **Пример**: `/start`
- **Ответ**:
  ```
  👋 Добро пожаловать в f2b-manager!
  Ваш chat_id: 123456789
  Добавьте этот ID в список администраторов в конфигурации.
  ```

### 2. `/help`
- **Доступ**: все пользователи
- **Назначение**: список команд, доступных текущему пользователю.
- **Аргументы**: нет
- **Пример**: `/help`

### 3. `/status`
- **Доступ**: авторизованные пользователи (admin / operator)
- **Назначение**: сводка состояния fail2ban: версия, состояние, время работы, число jail и блокировок.
- **Аргументы**: нет
- **Пример**: `/status`

### 4. `/jails`
- **Доступ**: авторизованные пользователи
- **Назначение**: список включённых jail с числом текущих блокировок и ошибок.
- **Аргументы**: нет
- **Пример**: `/jails`

### 5. `/banned`
- **Доступ**: авторизованные пользователи
- **Назначение**: сводный список IP, заблокированных во всех jail.
- **Аргументы**: нет
- **Пример**: `/banned`

### 6. `/jail <name>`
- **Доступ**: авторизованные пользователи
- **Назначение**: сведения об указанном jail: заблокированные IP, ошибки, `findtime`, `bantime` и другое.
- **Аргументы**:
  - `<name>`: обязательное имя jail, например `sshd`
- **Пример**: `/jail sshd`

### 7. `/ban <ip>`
- **Доступ**: **admin**
- **Назначение**: вручную блокирует IP через fail2ban `set <jail> banip`.
- **Аргументы**:
  - `<ip>`: обязательный IPv4/IPv6-адрес для блокировки;
  - jail по умолчанию — `sshd`; укажите другой через `@jail`, например `/ban 1.2.3.4@nginx-http-auth`.
- **Пример**: `/ban 1.2.3.4`
- **Примечание**: некорректный формат будет отклонён с пояснением.

### 8. `/unban <ip>`
- **Доступ**: **admin**
- **Назначение**: разблокирует IP через fail2ban `unban`.
- **Аргументы**:
  - `<ip>`: обязательный IP для разблокировки
- **Пример**: `/unban 1.2.3.4`

### 9. `/install`
- **Доступ**: **admin**
- **Назначение**: устанавливает fail2ban, определяет дистрибутив, использует пакетный менеджер и создаёт `jail.local` с Telegram action.
- **Аргументы**: нет
- **Пример**: `/install`
- **Примечание**: длительная операция; сначала отправляется сообщение о ходе установки, затем результат.

### 10. `/uninstall`
- **Доступ**: **admin**
- **Назначение**: удаляет fail2ban: останавливает и отключает сервис, удаляет пакет; резервную копию конфигурации можно сохранить.
- **Аргументы**: нет
- **Пример**: `/uninstall`
- **Внимание**: **опасная операция**; выполняется только после дополнительного подтверждения.

### 11. `/update`
- **Доступ**: **admin**
- **Назначение**: обновляет fail2ban до последней версии и перезапускает сервис.
- **Аргументы**: нет
- **Пример**: `/update`

### 12. `/reload`
- **Доступ**: **admin**
- **Назначение**: перезагружает конфигурацию fail2ban (`fail2ban-client reload`). Используйте после изменения jail.
- **Аргументы**: нет
- **Пример**: `/reload`

### 13. `/report`
- **Доступ**: авторизованные пользователи
- **Назначение**: формирует и отправляет текущий отчёт о блокировках.
- **Аргументы**: нет
- **Пример**: `/report`

### 14. `/whitelist`
- **Доступ**: **admin**
- **Назначение**: просмотр и управление белым списком fail2ban (`ignoreip`).
- **Аргументы**:
  - `add <ip>`: добавить IP/CIDR в белый список;
  - `del <ip>`: удалить IP из белого списка;
  - без аргументов: вывести текущий белый список.
- **Примеры**:
  - `/whitelist` → показать список;
  - `/whitelist add 203.0.113.5` → добавить;
  - `/whitelist del 203.0.113.5` → удалить.

### 15. `/setnotify <on|off>`
- **Доступ**: авторизованные пользователи (admin / operator)
- **Назначение**: включает и выключает уведомления в реальном времени о событиях блокировки/разблокировки.
- **Аргументы**:
  - `on`: включить;
  - `off`: выключить.
- **Пример**: `/setnotify off`

### 16. `/setschedule`
- **Доступ**: **admin**
- **Назначение**: задаёт периодичность и время плановых отчётов.
- **Аргументы**:
  - `daily <HH:MM>`: время ежедневного отчёта;
  - `weekly <day> <HH:MM>`: еженедельный отчёт (`day` — от monday до sunday);
  - `off`: отключить плановые отчёты.
- **Примеры**:
  - `/setschedule daily 08:00`
  - `/setschedule weekly monday 08:00`
  - `/setschedule off`

### 17. `/stats [days]`
- **Доступ**: авторизованные пользователи
- **Назначение**: статистика блокировок за последние N дней: число блокировок, уникальные IP и основные страны-источники.
- **Аргументы**:
  - `[days]`: необязательное число дней, по умолчанию 7.
- **Примеры**:
  - `/stats` → последние 7 дней;
  - `/stats 30` → последние 30 дней.
