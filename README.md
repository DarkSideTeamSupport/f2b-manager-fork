# f2b-manager

Система управления Fail2ban для VPS с Telegram-ботом, плановыми отчётами и уведомлениями в реальном времени.

## Возможности

- **Управление Fail2ban** — установка, удаление и обновление с поддержкой Debian, Ubuntu, CentOS, Rocky и других дистрибутивов.
- **Telegram-бот** — 18 интерактивных команд для удалённой проверки состояния, блокировки IP и управления сервисом.
- **Оповещения в реальном времени** — уведомления в Telegram при блокировке IP с данными о местоположении, количестве ошибок и совпавших строках журналов.
- **Плановые отчёты** — ежедневная и еженедельная сводка блокировок и список основных источников атак.
- **Резервный polling** — проверка состояния каждые 5 минут и отправка пропущенных уведомлений.
- **Проверка работоспособности** — контроль сервиса fail2ban, автоматический перезапуск и оповещение при ошибке.
- **Интерактивное меню** — запустите `f2b`, чтобы открыть меню управления и пошаговую настройку.

## Быстрая установка

### Пользователь root

```bash
curl -fsSL https://raw.githubusercontent.com/DarkSideTeamSupport/f2b-manager-fork/main/install.sh | bash
```

### Пользователь без root (требуется sudo)

```bash
curl -fsSL https://raw.githubusercontent.com/DarkSideTeamSupport/f2b-manager-fork/main/install.sh | sudo bash
```

### Альтернативный способ

```bash
git clone https://github.com/DarkSideTeamSupport/f2b-manager-fork.git /tmp/f2b-manager && bash /tmp/f2b-manager/install.sh
```

Скрипт автоматически обнаружит и установит отсутствующие системные зависимости, включая `python3-venv`, `python3-pip` и `git`.

После установки откроется интерактивное меню, в котором можно:
1. установить Fail2ban;
2. настроить Telegram Bot, указав Token и User ID;
3. запустить сервис.

Чтобы снова открыть меню позже, выполните `f2b`.

## Требования

- Linux VPS (рекомендуются Ubuntu 22.04 или Debian 12);
- Python 3.10+;
- права root;
- аккаунт Telegram для создания Bot.

## Создание Telegram Bot

1. Откройте Telegram и найдите `@BotFather`.
2. Отправьте `/newbot` и следуйте инструкциям.
3. Скопируйте выданный **Bot Token**.
4. Найдите `@userinfobot`, отправьте ему сообщение и получите свой **User ID**.

Мастер установки предложит указать оба значения.

## Использование

После установки отправляйте своему Bot команды в Telegram:

| Команда | Назначение |
|------|------|
| `/status` | Проверить состояние fail2ban |
| `/banned` | Показать список заблокированных IP |
| `/ban 1.2.3.4` | Заблокировать IP вручную |
| `/unban 1.2.3.4` | Разблокировать IP |
| `/report` | Немедленно сформировать отчёт |
| `/stats 7` | Показать статистику за 7 дней |
| `/help` | Показать все команды |

## Архитектура

```
VPS
├── f2b-manager (демон под управлением systemd)
│   ├── модуль управления Fail2ban
│   ├── Telegram Bot (18 команд, трёхуровневая авторизация)
│   ├── уведомления в реальном времени (action hook + резервный polling)
│   └── планировщик задач (APScheduler)
├── Fail2ban (системный сервис)
│   └── action telegram-notify → notify.sh → f2b-manager
└── база состояния SQLite
```

## Технологии

Python 3.10+ / python-telegram-bot / APScheduler / SQLite / systemd
